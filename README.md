# Andrade TagTool Manager — Windows

Instaladores oficiais para Windows 10 e 11 (64 bits).

[Baixar instalador 0.3.19 com backend local](https://github.com/ANDRADESOLUCOESELETRICAS-ux/andrade-tagtool-downloads/releases/download/v0.3.19/Andrade-TagTool-Manager-Setup-0.3.19.exe)

[Ver a versão mais recente e os arquivos de verificação](https://github.com/ANDRADESOLUCOESELETRICAS-ux/andrade-tagtool-downloads/releases/latest)

O backend local exige importar a configuração protegida com a mesma chave de criptografia do servidor existente. Para acesso por outros dispositivos, é necessário um túnel HTTPS.

[Guia de ativação do backend local](https://github.com/ANDRADESOLUCOESELETRICAS-ux/andrade-tagtool-downloads/releases/download/v0.3.19/ativar-backend-local-0.3.19.md)
